# Toy Shop Template (Express + EJS + Bootstrap)

A simple toy shop website template using HTML, CSS, Bootstrap 5, and a Node.js (Express) backend with EJS templates.

## Features
- Home, Shop, Product detail, Contact, and 404 pages
- EJS layouts and partials
- Sample product data
- Bootstrap 5 styling + custom CSS

## Requirements
- Node.js 18+

## Setup
```bash
npm install
npm run dev
```
App runs at http://localhost:3000

## Build/Run
```bash
npm start
```
